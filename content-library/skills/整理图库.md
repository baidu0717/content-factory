# 整理图库

细分「可复用素材」文件夹，将无人出镜的图片自动分入子文件夹。

## 使用场景

用户已用 Python 工具完成人工粗筛，「可复用素材」文件夹里有无人出镜的景点/酒店/餐食图片，需要细分到子文件夹。

## 步骤

1. 询问用户：可复用素材文件夹的完整路径
2. 列出文件夹内所有图片文件名
3. 读取图片，识别内容类型：
   - 酒店客房 / 酒店公共区域 / 酒店早餐
   - 餐食（菜品特写、餐厅环境）
   - 法国景点（巴黎/普罗旺斯/里昂等）
   - 意大利景点（罗马/米兰/佛罗伦萨/威尼斯等）
   - 瑞士景点（采尔马特/卢塞恩/因特拉肯等）
   - 交通（火车/飞机/机场）
   - 其他（不确定归这里，附上图片名让用户确认）
4. 在可复用素材文件夹内创建对应子文件夹（仅创建实际有图片的分类）
5. 移动图片到对应子文件夹
6. 汇报：各子文件夹数量，「其他」类需用户确认的列表

## 注意

- 无需用户二次确认（识别「是什么」准确率高）
- 「其他」类除外，需列出让用户看
