## 业务背景
我们是一家中国旅行社，专门为中国大陆客人及海外华人提供欧洲旅游服务，主营两类产品：

- **定制游**：客人对现有小团路线不满意，或有个性化需求，由我们量身规划行程。人数多为 2-6 人，偶尔更多。
- **小团游**：我们提供固定路线的 4-6 人小团，行程不作调整。通常客人只有 2 人，希望通过拼团降低费用，凑满 4-6 人后出发。

申根签证是出行前的必要准备，也是整个流程最靠前的一环——客人需先拿到签证，再预订机票、酒店、门票等资源。因此我们将签证状态纳入客户跟进体系：
- 出发时间 - 2个月 = 签证启动节点 = 关键跟进时间点
- 在此节点主动联系客人，提醒启动签证，同步推进行程规划

获客渠道：聚光投放（付费广告）/ 素人（有机内容）/ 抖音

## 跟进时间规则
- 出发时间 - 2个月 = 下次跟进时间（提醒客人启动签证流程）
- 下次跟进时间已过 → 设为今天 + 跟进情况改为"立马跟进"
- 未回复 → 跟进情况设为"立马跟进"（需主动推进）
- 「帮客户代办签证但还未开始」→ 后续跟进；「签证已在办理中」→ 办理签证中

## 飞书表格字段格式（经测试确认）

| 字段名 | API 格式 | 备注 |
|--------|---------|------|
| 微信昵称 | 字符串 | |
| 渠道 | 单选，字符串 | "聚光投放" / "素人" / "抖音" |
| 跟进情况 | 多选，字符串数组 | 见下方选项 |
| 目的地 | 多选，字符串数组 | 见下方选项 |
| 出发时间 | 日期，毫秒时间戳 | |
| 人数 | 数字 | |
| 详细情况 | 字符串 | |
| 下次跟进时间 | 日期，毫秒时间戳 | |

跟进情况可选值：放弃 / 后续跟进 / 立马跟进 / 办理签证中 / 已有（办）签证

目的地可选值：法意瑞 / 南法 / 南意 / 冰岛 / 挪威

打标规则：
- 法意瑞 已包含法国+意大利+瑞士，不需单独打法国/意大利/瑞士标签
- 南法（尼斯、普罗旺斯、马赛等）→ 额外打「南法」
- 南意（西西里、那不勒斯、阿马尔菲等）→ 额外打「南意」
- 目的地不在选项内的（如西班牙）→ 写入详细情况，目的地字段用最接近的选项

**更新记录用 PUT，不是 PATCH**

## 执行步骤（无需用户确认，直接写入）

**第一步：提取信息 + 计算时间戳**

从用户描述中提取所有字段，并用 bash 计算时间戳：

```bash
python3 -c "
import datetime
depart = datetime.datetime(YYYY, M, D)   # 替换为出发时间最早日期
followup = datetime.datetime(YYYY, M, D) # 替换为出发时间 - 2个月
print(int(depart.timestamp()*1000), int(followup.timestamp()*1000))
"
```

**第二步：获取 token**

```bash
curl -s -X POST 'https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal' \
  -H 'Content-Type: application/json' \
  -d "{\"app_id\": \"$FEISHU_APP_ID\", \"app_secret\": \"$FEISHU_APP_SECRET\"}"
```

**第三步：直接写入飞书**

```bash
curl -s -X POST "https://open.feishu.cn/open-apis/bitable/v1/apps/SafebsC0CaX28ps66DdcPcwKnSb/tables/tblLUsY7ZXdlV8k0/records" \
  -H "Authorization: Bearer {tenant_access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "fields": {
      "微信昵称": "...",
      "渠道": "...",
      "跟进情况": ["..."],
      "出发时间": TIMESTAMP,
      "人数": X,
      "详细情况": "...",

    }
  }'
```

**第四步：输出结果**

写入成功后简洁显示：


如有多个客户，逐条写入，全部完成后汇总：
```

  - 昵称A｜X月出发｜下次跟进：X月X日
  - 昵称B｜X月出发｜下次跟进：X月X日
```
