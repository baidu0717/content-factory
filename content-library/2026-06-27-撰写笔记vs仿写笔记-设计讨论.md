# 撰写笔记 vs 仿写笔记：设计讨论记录
*2026-06-27*

---

## 一、两种 skill 的根本区别

### 撰写笔记（内容决定结构）

流程：先选图 → AI读图产出事实清单 → 确定必写证明点 → 出配对表 → 再选模板/参考笔记 → 写稿

逻辑：先知道"这篇要证明什么"，然后找结构来承载内容。结构是为内容找来的。

### 仿写笔记 / 结构决定内容的提示词

流程：看到一组图 → 立刻联想到某篇参考笔记的节奏 → 用那篇笔记作骨架 → 只提交有卖点的图（不提交全部）→ AI确认图片事实 → 按参考笔记结构填入内容

逻辑：参考笔记的节奏先确定，证明任务在这个结构里找位置插入。

### 关键差异：谁来连接"图片"和"卖点"

| | 撰写笔记 | 仿写笔记 |
|---|---|---|
| 连接工作由谁做 | AI（配对表） | 用户（直接声明） |
| 提交图片数量 | 全部 | 只提交有卖点的图 + 封面 |
| 参考笔记来源 | AI从库里选，用户确认 | 用户直接指定 |
| 结构严格度 | 感受节奏即可 | 严格对齐每段收尾方式 |
| 适用场景 | 从零开始，不确定用哪个结构 | 已有目标参考笔记，知道要仿谁 |

## 二、天花板讨论

### 仿写笔记的天花板

**结构创新天花板偏低**：输出结构被参考笔记框住，很难超出原文的结构层面。

**单篇输出质量不一定低**：参考笔记提供节奏和声音，但内容（客人场景/证明细节）可以比原文更好。天花板 = 原文节奏 × 用户内容质量，两者都可以高。

**库决定上限**：仿写的天花板直接等于参考笔记库的天花板。库里最好的那篇就是上限，库不更新，天花板不动。

### 撰写笔记的天花板

理论上更高，因为可以组合多篇参考笔记的优点，甚至生成新结构。但方差大——跑得好能超越任何单篇参考笔记，跑得不好写成流水账（今天的测试是例子）。

### 实际选择逻辑

| | 仿写笔记 | 撰写笔记 |
|---|---|---|
| 天花板 | 稍低但稳 | 更高但不稳 |
| 适合用户 | 熟悉素材库，看图能联想到参考笔记 | 不确定结构，需要AI辅助推导 |

## 三、关于借用原文内容的边界（重要）

**我们做的是商业内容，不是学术作文。**

可以：
- 直接借用某一句话
- 直接借用某个开头或结尾
- 直接借用某一段甚至两段
- 拆句发散出更好的表述
- 沿用原文的语气词/情绪标记/句式节奏自然写出

为什么借用两段也没问题：内容本身（人物/路线/场景）会随客人情况调整，整体读感已经不同。

**唯一边界：整体读起来不让人一眼认出是同一篇笔记，能通过小红书审核即可。**

不是：七八成相似度这种数字限制（已从两个skill中删除）

## 四、今天测试暴露的问题（2026-06-27 实测）

### 问题一：仿写只仿了结构，没仿声音

错误做法：提取段落顺序 → 用新内容填 → 把句子整理通顺
结果：结构对，声音死。每句话都工整完整，像写作文。

正确做法：借用原文的语言锚点（竟然/真的好幸运/哈哈哈哈/不肯走/恨不得），用这些词把新内容包裹起来。这些词是声音的载体。

### 问题二：说话人视角失位

错误：站在第三方旁观者视角写（"两位老人、两个孩子"这种罗列）
正确：妈妈视角，有关系感（"爸妈""老公""两个孩子"），有具体的自嘲和担心

### 问题三：自我定位要从源笔记推导

错误：不知道主角自我定位时去问用户
正确：读源笔记，找到说话人的局限/自嘲（英文废/拖家带口/没胆）→ 推导本篇主角的对应局限（六口人/年龄跨度大/以前没敢想出欧洲）→ 用同样语气写出

### 问题四："不复用原文句子"这条指令本身有问题

之前skill里写的"不复用原文句子"导致AI把所有语气词都换成书面版，声音死掉。
已修正：两个skill的借用规则全部改为"借用不设上限，唯一边界是不让人一眼认出是同一篇"。

## 五、建议用法

**有明确参考笔记时**：直接用 `/仿写笔记`，用户指定源笔记+声明图片用途，AI严格对齐结构写稿。

**没有明确参考笔记时**：用 `/撰写笔记`，AI辅助推导证明点和配对，再找参考笔记写稿。中间步骤多，对AI执行质量要求更高。

**混合用法**：用 `/撰写笔记` 跑到配对表确认那步（内容规划），然后切换成仿写思路执行写稿（严格对齐源笔记结构）。
